Opens any video or audio file FFmpeg can read, including security-camera recordings.

- Dahua and other DVR/NVR .dav recordings now open and convert, sound included, even exports with unusual file headers. Raw .264/.265 camera streams work too.
- The Windows file picker now shows all files, so nothing is hidden.
- Right-click any file and choose Open with > Media Converter, or drag files onto the app's icon (Windows).
- 13 more formats under "More": AVI, WMV, FLV, MPEG-2, TS, 3GP and OGV video; AAC, WMA, AIFF, Opus, AC3 and ALAC audio.
- Trimming camera recordings now works, and 5.1 surround sound converts to WMA and WMV.
