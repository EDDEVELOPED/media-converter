Windows now open in front.

- The Media Converter window, the Add files picker and the Save to folder picker open on top of your other windows instead of hiding behind them. After a picker closes, you're back in Media Converter.
- Show in folder brings the Explorer window to the front.
- Opening Media Converter while it's already running brings its window up instead of opening a second one.
- Empty files (0 bytes), such as a recorder export that didn't finish, now say so instead of suggesting the file is encrypted.
